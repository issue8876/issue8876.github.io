대화와 데이터는 어떻게 다뤄질까?

OpenAI 연결 구현 기준: 2026년 10월 27일 · 연결 준비 상태는 앱의 AI 대화 설정에서 확인 · 서비스 주소: maeum.web.app

기본 활동의 화면 지우기와 외부 서비스의 데이터 처리는 달라. 이름을 쓰지 않아도 이야기 내용만으로 누군지 알아볼 수 있어.

어디로 무엇을 보내나요?

기능보내는 내용과 처리
기본 활동점검 답과 대화, 계획은 열린 화면의 메모리에서 처리합니다. 앱은 이 내용을 서버의 대화 기록이나 데이터베이스에 저장하지 않습니다. 사이트에 접속하기 위한 요청 정보는 별개입니다.
AI 연결숫자 코드는 Firebase 서버에서 검증합니다. 성공하면 1시간 동안 유효한 연결 토큰을 화면 메모리에 둡니다. 코드·토큰을 OpenAI 대화 본문에 넣지 않습니다. App Check는 기기·사이트의 연결 확인에 사용됩니다.
AI 대화전환 코드의 제공사는 OpenAI이며 모델은 GPT-6.1 Terra입니다. 연결한 뒤 나눈 최근 최대 16개 대화(직접 쓴 말·선택한 말·답변), 학년, 주제, 고른 기분을 Firebase 서버를 거쳐 OpenAI Responses API로 보냅니다. 점검의 숫자 응답은 보내지 않습니다. 이름·학교·연락처 등을 프로그램으로 가리지만 모두 찾아내지는 못합니다.
읽어주기선택한 음성 모델을 내려받고 읽을 문장은 기기에서 합성합니다. 대체 음성도 기기에 설치된 한국어 음성만 사용합니다. 음성 파일 캐시는 대화를 담고 있지 않습니다.
말로 입력하기선택하기 전에 별도로 확인합니다. 브라우저의 음성 인식 서비스로 음성이 전송될 수 있으며, 처리·보관은 해당 브라우저 제공자의 정책에 따릅니다.

누가 볼 수 있고 얼마나 남나요?

  • 앱에는 교사의 대화 열람 화면, 학생별 기록 목록, 자동 공유 기능이 없습니다. 화면을 함께 보거나 학생이 직접 보여준 내용은 상대방이 볼 수 있습니다.
  • 앱 서버는 대화 본문·숫자 코드·API 키를 운영 로그에 출력하지 않습니다. 요청 시각·상태·IP 등 접속 정보는 Google Cloud 운영 로그에 포함될 수 있습니다. 확인한 보관 설정은 일반 로그 30일, 필수 관리·감사 로그 400일입니다. 필수 로그가 대화 원문을 저장한다는 뜻은 아닙니다.
  • OpenAI 요청에는 store: false와 background: false를 사용합니다. 저장 대화·파일·외부 도구를 사용하지 않고 매 요청에 필요한 문맥을 보냅니다.
  • 이 앱은 ZDR(Zero Data Retention)을 적용하지 않은 일반 OpenAI API 방식으로 연결합니다. store: false는 응답 객체 저장을 요청하지 않는 설정이며 OpenAI의 안전 점검용 보관까지 해제하지는 않습니다. 일반 API의 안전 점검 로그에는 입력·응답 등이 포함되어 기본적으로 최대 30일 보관될 수 있으며 공식 정책의 예외가 적용될 수 있습니다.
  • OpenAI API 데이터는 별도 공유에 동의하지 않는 한 기본적으로 모델 학습에 사용되지 않습니다. ZDR 적용 범위·기능별 제한 및 예외는 공식 문서를 따릅니다. Firebase 접속·관리 로그와 브라우저 음성 서비스는 OpenAI ZDR과 별개입니다.

지우거나 문의하고 싶다면

‘새로 쓰기’에서 대화 지우기를 선택하거나 새로고침하면 현재 화면의 대화·점검·계획·연결 토큰이 사라집니다. ‘연결 끝내기’는 앞으로의 AI 전송을 멈추며, 현재 보이는 대화까지 지우려면 ‘새로 쓰기’를 이용합니다. 외부 서비스의 처리 내역이나 운영 로그까지 이 버튼으로 삭제되지는 않습니다.

앱 자체에 저장된 대화 원문이나 연구용 응답 자료는 없으므로 이를 내려받거나 개별 삭제하는 관리 기능도 없습니다. 외부 서비스의 데이터 처리 관련 요청은 해당 서비스·프로젝트 운영자를 통한 처리가 필요합니다.

운영기관·담당자·공개 문의처: 미등록. 운영자가 문의 및 삭제 요청 창구를 등록하기 전에는 이 페이지가 완전한 운영기관 개인정보 처리방침을 대신하지 않습니다. 문의를 위해 대화나 개인정보를 공개 게시물에 올리지 마세요.

근거와 확인 범위

확인한 구현: 대화 DB 쓰기 없음, 서버 본문 로깅 없음, 요청 전 개인정보 가림, 만료 토큰, OpenAI 응답 저장 해제 요청. 자동 테스트는 모의 응답으로 수행했습니다. 앱의 준비 상태가 키 유효성·결제·제공사 보관 상태를 실시간 검증하는 것은 아닙니다.
