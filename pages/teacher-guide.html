마음쉼 · 교사용 한 장 수업 안내

10~15분 선택형 활동 · maeum.web.app · 2026-10-20 · 인쇄할 때 A4 1쪽 구성

목표: 자기 상황에 맞는 행동 하나를 정하고, 막힐 때 도움받을 방법을 말할 수 있다. 개인 감정·점검 답·대화 공개는 선택이며 학급 화면에 자동 공유하지 않는다.

학년별 사용

  • 초등 1–3학년: 15분. 쉬운 낱말 설명·예시와 응답 연습을 함께 읽는다. 선택지 간 차이를 학생의 말로 들어본다.
  • 초등 4–6학년: 10~15분. 설명을 읽고 선택 → 다음 → 필요하면 이전 답 수정.
  • 중·고등학생: 10분. 스스로 선택하고 계획의 현실성과 도움 경로를 돌아본다.

학년 선택은 설명과 AI 말투를 바꾸며, 점검의 6문장과 6단계 구조는 같다.

수업 흐름과 발문

  1. 1~2분: “오늘은 어려운 일을 해볼 방법을 찾아보자. 말하고 싶지 않은 내용은 말하지 않아도 돼.”
  2. 3분: 점검·상황 선택·숨 고르기 중 하나를 고른다. “어떤 뜻으로 골랐니?”
  3. 3~4분: 행동과 시점, 막힐 때 도움받을 사람을 정한다. “지금 할 수 있을 만큼 작을까?”
  4. 2~3분: 원하면 계획만 공유하거나 가상 사례로 연습한다.
  5. 1~2분: “해본 뒤 무엇을 다시 살펴볼까?”

무엇을 돌아보나요?

부제는 ‘시작하는 힘과 방법 찾기 돌아보기’다. 사용자 제공 Dify ‘마음길 코치.yml’이 Snyder 등(1997)의 Children's Hope Scale(CHS) 6문항·6점 구조를 참고했다고 명시한 교육용 표현 6문장을 유지했다. 공식 한국어판·표준화 검사로 소개하지 않는다.

2026-10-20 개선에서 문장별 낱말 설명·예시를 추가하고, 응답 표현을 ‘전혀 없어 / 아주 드물어 / 가끔 그래 / 자주 그래 / 거의 항상 그래 / 항상 그래’로 빈도에 맞춰 정리했다. 검증된 원척도 판본의 번역이나 점수가 아니다.

원 저작물과 승인된 번역의 사용 조건은 확인되지 않았다. 논문 측정·효과 비교·심리 선별에는 승인된 판본과 별도 타당화가 필요하다. 총점·등급·임상 기준·능력 비교를 제공하지 않는다. 원 논문: Snyder et al., 1997, J. Pediatric Psychology, 22(3), 399–421.

관찰과 안전한 활용

  • 관찰: 행동을 하나 정했는지, 시점을 말했는지, 도움 경로를 떠올렸는지. 감정 호전이나 점수 상승으로 평가하지 않는다.
  • 점검은 건너뛰어도 된다. 위기 표현이 감지되면 AI 연결 없이 도움 안내로 이동한다.
  • 위기 표현 탐지는 보조 수단이다. 학생의 표정·행동·간접 표현도 살피고 학교의 실제 보호 절차를 따른다. 앱은 자동 연락·긴급 구조를 하지 않는다.

AI 사용 전 확인

기본 활동은 AI 연결 없이 가능하다. 현재 공개 Gemini API 약관은 18세 미만이 접근할 가능성이 높은 앱을 제한한다. 연구·시범이나 숫자 코드가 예외를 뜻하지 않으므로 실제 학생 AI 이용은 적용 계약·허용 범위를 별도로 확인해야 한다.

운영기관·담당자·문의처는 미등록이다. 상세 전송·보관·삭제 조건은 ‘대화·데이터 안내’를 확인한다. 학교·학급별 접근 분리와 실제 학생 대상 사용성·효과 검증은 별도 수행 항목이다.

수업안은 콘텐츠 분석에 따른 제안이며 앱의 교육 효과 검증 결과가 아닙니다. 개인정보 없이 계획만 선택 공유합니다.
